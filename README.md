# ⚾ KBO AI Brief - 실시간 KBO 야구 경기 정보 & AI 관전 포인트

KBO 리그 실제 정규시즌 실시간 팀 순위(1위 삼성 라이온즈 54승 34패 등), 경기 스코어보드, 네이버 스포츠 기반 주요 선수 세부 기록 및 OpenAI GPT-4o 기반 경기 프리뷰/리뷰 요약을 제공하는 현대적인 야구 정보 대시보드 웹 애플리케이션입니다.

---

## 🌟 주요 구현 기능 (Phase 1 MVP + Real KBO Data)

### 1. 🏆 2026 KBO 실제 정규시즌 실시간 팀 순위 연동
- **실시간 네이버 KBO API 연동**: `https://api-gw.sports.naver.com/statistics/categories/kbo/seasons/2026/teams` API 기반 10개 구단 최신 순위 연동.
- **실제 1위 팀 표출**: 삼성 라이온즈(1위 54승 34패), KT 위즈(2위 51승 35패 7연승), LG 트윈스(3위 52승 38패) 등 오차 없는 실제 수치 렌더링.
- **순위 변동 & 포스트시즌 진출권**: 전날 대비 순위 변동 수치 및 1~5위 포스트시즌 진출권 하이라이트.

### 2. ⭐ 관심 구단 (MY 팀) 선택 & 경기 최상단 핀 고정
- **선호 구단 지정**: `삼성 라이온즈`, `한화 이글스`, `LG 트윈스`, `KIA 타이거즈` 등 본인의 관심 구단을 선택 가능.
- **최상단 핀 고정**: 선택된 MY 팀의 경기가 대시보드 맨 위로 자동 정렬.
- **LocalStorage 영속성**: 브라우저를 닫았다 열어도 선호 구단 설정 지속 유지.

### 3. 📅 일자별 경기 스코어 & 30초 실시간 자동 갱신 (LIVE)
- **일자별 스코어보드**: 어제 / 오늘 / 내일 경기 일정 및 이닝 스코어 표출.
- **30초 실시간 폴링**: 진행 중인 경기(`IN_PROGRESS`)의 이닝 상태 및 점수 30초 간격 자동 갱신.
- **상태별 알약 필터**: `전체`, `진행중`, `종료`, `예정` 수치 필터링.

### 4. ⭐ 네이버 스포츠 기준 주요 선수 세부 기록 (Top 5 랭킹)
- **투수 랭킹**: 양현종, 류현진, 원태인, 김광현, 곽빈 (ERA, 승/패/세, WHIP, 삼진, WAR)
- **타자 랭킹**: 김도영(38홈런/109타점/WAR 8.32), 구자욱, 노시환, 최정, 박해민 (AVG, HR, RBI, OPS, WAR)

### 5. 📜 2025 전년도 성적 & 챔피언 복기
- **전년도 기록 탭**: 2025년 최종 순위, 승률, 포스트시즌 진출 결과 표 표출.

### 6. 🔮 AI 관전 포인트 & 📊 AI 경기 요약 모달
- **AI Preview / Review**: 경기 관전 포인트 및 실시간 승패 결정적 요인 모달 UI 렌더링.
