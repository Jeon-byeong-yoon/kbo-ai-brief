# 매직넘버 / 트래직넘버

매직넘버는 "내 승리 + 경쟁팀 패배" 가 앞으로 몇 번 더 쌓이면 순위가 확정되는지다.
둘 중 어느 쪽으로 채워도 상관없다. 트래직넘버는 방향을 뒤집은 것으로, 0 이 되면
탈락이다.

새 API 가 필요 없다. 승·패·무만 있으면 계산된다.

## 흔히 쓰는 공식은 KBO 에 맞지 않는다

보통 이렇게 쓴다.

```
매직넘버 = (상대의 최대 승수) - (내 승수) + 1
```

이건 **승수로 순위를 매길 때** 맞는 식이다. KBO 는 승수가 아니라 **승률**로 매기고,
승률은 무승부를 뺀 `승 / (승 + 패)` 다. 그래서 무승부 수가 다르면 승수가 많은 팀이
뒤로 갈 수 있다.

| 팀 | 성적 | 승률 |
| :--- | :--- | ---: |
| A | 80승 64패 0무 | .556 |
| B | 79승 60패 5무 | .568 |

A 가 한 경기 더 이겼는데 B 가 앞선다. 2009년처럼 무승부를 승률에 넣던 시절에는
차이가 더 컸다(`docs/PREDICTION.md` 참고).

## 그래서 가능한 결과를 직접 따진다

두 팀 사이의 매직넘버를 이렇게 구한다.

- **나**: 남은 경기에서 `a` 승, 나머지는 전부 패로 본다.
  무승부는 분모(`승 + 패`)를 줄여 승률을 **올려** 주므로, 전패가 나에게 가장 불리하다
- **상대**: `b` 패, 나머지는 전부 승으로 본다.
  무승부는 상대 승률을 **낮추므로**, 전승이 나에게 가장 불리하다

```
내 승률   = (내 승 + a) / (내 승 + 내 패 + 내 잔여)
상대 승률 = (상대 승 + 상대 잔여 - b) / (상대 승 + 상대 패 + 상대 잔여)
```

`a + b` 가 M 이상인 모든 경우에 내 승률이 상대보다 **높은**, 그런 가장 작은 M 이
매직넘버다. `a` 나 `b` 가 늘면 결과는 나에게 유리해지기만 하므로 `a + b === M` 인
경우만 확인하면 된다.

동률은 확정으로 보지 않는다. KBO 는 동률을 상대전적으로 가리므로 보장이 아니다.

## 한 팀 대 한 팀에서 순위 전체로

- **정규시즌 1위** — 아홉 팀을 전부 제쳐야 하므로 **가장 큰** 매직넘버를 쓴다.
  한 팀이라도 제칠 수 없으면 1위는 산술적으로 불가능하다
- **포스트시즌 진출** — 다섯 자리 안에 들면 된다. 확실히 이기는 팀이 다섯이면
  나보다 앞설 수 있는 팀이 넷 이하이므로 진출이 확정된다. 그래서 아홉 팀에 대한
  매직넘버 중 **다섯 번째로 작은** 값을 쓴다
- **트래직넘버** — 상대가 나를 제치는 데 필요한 수를 같은 방식으로 구한다.
  1위 탈락은 그중 가장 작은 값(한 팀만 확정돼도 밀린다),
  포스트시즌 탈락은 다섯 번째로 작은 값이다

## 남은 경기는 144 기준으로 센다

일정 API 가 주는 잔여 경기가 아니라 `144 - 치른 경기` 를 쓴다. 우천 순연 후 편성일이
공지되지 않은 경기는 일정에 없지만 어차피 치르기 때문이다. 실제로 2026-09-26 기준
일정에는 46경기만 있었고 실제 잔여는 56경기였다.

이건 우승 확률 시뮬레이션과 다른 선택이다. 시뮬레이션은 **어느 팀이 어느 팀과**
붙는지 알아야 해서 없는 일정을 지어낼 수 없지만, 매직넘버는 경기 수만 알면 된다.

## 검산 (2026-09-27)

| 순위 | 팀 | 성적 | 잔여 | 1위 | PS |
| ---: | :--- | :--- | ---: | ---: | ---: |
| 1 | KT | 80승 49패 4무 | 11 | 9 | 확정 |
| 2 | 삼성 | 78승 52패 3무 | 11 | 14 | 확정 |
| 3 | LG | 75승 57패 1무 | 11 | 18 | 확정 |
| 4 | KIA | 72승 58패 2무 | 12 | 21 | 2 |
| 5 | 두산 | 67승 62패 5무 | 10 | — | 5 |
| 9 | 한화 | 54승 76패 4무 | 10 | — | 탈락 |

손으로 확인한 것들이다.

- **LG 포스트시즌 확정** — LG 가 남은 11경기를 전패해도 승률 75/143 = .524 다.
  6위 NC 는 다 이겨도 73/142 = .514 로 못 넘는다. LG 를 넘을 수 있는 팀은
  KT·삼성·KIA·두산 넷뿐이므로 다섯째 자리 안이 보장된다
- **한화 탈락** — 한화가 다 이겨도 최대 64/140 = .457 이다. KT·삼성·LG·KIA·두산
  다섯 팀은 전패해도 그보다 높다(두산이 가장 낮아 67/139 = .482).
  다섯 팀이 확실히 앞서므로 탈락이다
- **KT 1위 매직 9** — 가장 위협적인 삼성의 최대치는 89/141 = .631 이다.
  `a + b = 9` 중 가장 불리한 `a=0, b=9` 에서 KT 80/140 = .5714,
  삼성 80/141 = .5674 로 KT 가 앞선다. `M = 8` 이면 `a=0, b=8` 에서
  KT .5714, 삼성 81/141 = .5745 로 뒤집히므로 9 가 맞다
