# 우승 확률 예측

`/predictions` 에서 보는 숫자가 어떻게 나오는지, 그리고 얼마나 믿을 수 있는지 적는다.

## 먼저: 학습한 모델이 아니다

"과거 데이터로 우승을 예측하는 모델을 학습시킨다"는 접근은 이 문제에 쓸 수 없다.
**우승 사례가 시즌당 하나뿐이라 2008~2025 를 다 써도 18개**다. 팀 타율·팀 평균자책·
선수 뎁스를 피처로 넣으면 금방 10~20개가 되는데, 표본 18개에 피처 20개면 모델이
학습하는 게 아니라 외운다. 게다가

- 8구단에서 10구단으로 바뀌었고 (2013·2015년 확장)
- 2019년 공인구 변경으로 득점 환경이 크게 달라졌으며
- 18개 중 4개가 삼성 왕조(2011~2014)라 실질 독립 표본은 더 적다

그래서 **시뮬레이션**으로 간다. 학습은 우승이 아니라 경기 단위로 한다.

## 모델 상수는 측정했다

가정하지 않고 2008~2025 실제 경기에서 뽑았다.

| 상수 | 값 | 근거 |
| --- | --- | --- |
| 홈 승률 | **0.5196** | 정규시즌 9,732경기(무승부 제외) 중 홈 4,961승 4,586패 |
| 피타고리안 지수 | **1.80** | 140 팀-시즌에 대해 잔차가 최소가 되는 값 (RMSE 0.0268) |

둘 다 야구 통계에서 통용되는 값(홈 0.54 안팎, 지수 1.83)과 가까워서 측정이
제대로 됐다고 본다. 정규시즌 구간은 `docs/DATA-SOURCES.md` 에 적은 방법으로 가려냈다.

## 전력 추정

팀마다 세 가지를 구해 섞는다.

1. **피타고리안 승률** — `득점^1.8 / (득점^1.8 + 실점^1.8)`.
   승패 기록보다 팀 실력을 잘 나타낸다
2. **실제 승률** — 실제로 거둔 성적. 운도 포함돼 있다
3. **뎁스 승률** — 소속 선수 WAR 합을 승률로 환산. `(43 + WAR) / 144`.
   대체 선수로만 채운 팀이 144경기에서 약 43승 한다고 보는 기준점이다.
   선수 데이터는 `pageSize=500` 으로 팀당 24~41명씩 전체 로스터를 받는다

```
전력 = 0.5 + (피타 x 0.45 + 실제 x 0.25 + 뎁스 x 0.30 - 0.5) x 0.8
```

마지막 0.8 은 평균 회귀다. 세 추정치 모두 완벽하지 않으므로 .500 쪽으로 20% 당긴다.

화면의 표에 이 세 값과 전력을 모두 그대로 보여준다. 어느 팀의 확률이 왜 그렇게
나왔는지 숫자로 따라갈 수 있어야 한다는 뜻이다. 예를 들어 2026 한화는 실제 승률이
.419 인데 피타고리안이 .496, 뎁스가 .528 이라 전력은 .489 로 잡힌다.
득실차에 비해 승수가 적었던 팀이라는 게 드러난다.

## 시뮬레이션

두 팀의 승부는 log5 로 계산하고, 측정한 홈 승률만큼 오즈에 곱해 홈 이점을 넣는다.

```
P(A승) = (a - a x b) / (a + b - 2 x a x b)
```

한 번의 시뮬레이션은 이렇게 돈다.

1. 남은 정규시즌 경기를 모두 치른다
2. 최종 승률로 순위를 매긴다
3. 포스트시즌을 치른다
   - 와일드카드: 4위 홈 최대 2경기. 4위는 1승만 해도 올라가므로 5위는 2연승해야 한다
   - 준플레이오프: 3위 vs 와일드카드 승자, 5전 3선승
   - 플레이오프: 2위 vs 준PO 승자, 5전 3선승
   - 한국시리즈: 정규 1위 vs PO 승자, 7전 4선승
4. 우승 팀을 기록한다

기본 20,000회 반복한다. 난수는 시드를 고정해서 같은 입력이면 같은 결과가 나온다.

확률 합계로 자체 검증한다. 우승 100%, 한국시리즈 진출 200%, 포스트시즌 진출 500%,
정규시즌 1위 100% 가 나와야 한다.

## 검증 — 과거 18시즌

각 시즌의 최종 성적을 넣고 포스트시즌을 시뮬레이션한 뒤 실제 우승팀과 대조했다.
배포되는 코드를 그대로 호출해서 얻은 결과다.

| | 결과 |
| --- | --- |
| 모델 1순위가 실제 우승팀 | **15 / 18 (83%)** |
| 정규시즌 1위가 우승 (기준선) | 16 / 18 (89%) |
| 실제 우승팀에 부여한 평균 확률 | **49.6%** (무작위면 10%) |

연도별로 보면 빗나간 세 번은 이렇다.

- **2009** — 실제 KIA 우승. 모델은 SK 를 1순위(58.6%)로 두고 KIA 에 26.6% 를 줬다.
  SK 의 득실차와 WAR 이 KIA 보다 좋아서 순위를 뒤집은 경우다
- **2015** — 실제 두산 우승(정규 3위). 모델은 두산에 7.5% 밖에 주지 않았다
- **2018** — 실제 SK 우승(정규 2위). 모델은 SK 에 20.5%

**모델의 1순위 적중률(83%)이 "정규시즌 1위가 우승한다"는 단순 기준선(89%)보다 낮다.**
이걸 숨기지 않고 적는다. 다만 이 모델의 목적은 1순위를 맞히는 게 아니라 확률 분포를
내는 것이다. 실제 우승팀에 평균 49.6% 를 부여했고 이는 무작위(10%)보다 훨씬 낫다.
2015·2018 처럼 하위 시드가 우승한 해는 어떤 모델도 맞히기 어렵다.

가중치를 18개 결과에 맞춰 조정하면 적중률은 올릴 수 있다. 하지만 그게 바로 맨 위에서
피하려 한 과적합이라 하지 않았다. 지금 가중치는 야구 통계에서 통용되는 근거
(피타고리안이 승패 기록보다 예측력이 좋다)에 따라 정했고, 화면과 이 문서에 그대로
공개한다.

## 한계

- 부상·트레이드·선수 기용 변화를 모른다. 시즌 누적 성적만 본다
- 선발 로테이션을 구분하지 않는다. 단기전에서 에이스 등판 여부는 큰 변수인데 반영이 없다
- 팀 WAR 은 네이버가 주는 선수 목록의 합이라 전체 로스터와 정확히 같지는 않다
- 동률 처리는 난수로 가른다. 실제 KBO 는 상대전적 등으로 가린다
- 2007년 이전은 데이터가 없어 검증 표본을 더 늘릴 수 없다
- 우천 순연 후 편성일이 아직 공지되지 않은 경기는 일정에 없어 시뮬레이션에서 빠진다.
  2026-09-26 기준 잔여 56경기 중 46경기만 일정에 올라와 있었고, 팀별로도 고르지 않았다
  (두산 0경기 누락, KT·KIA·LG·롯데 각 3경기). 빠진 몫을 평균 상대와의 중립 경기로
  메우는 방법도 있지만 쓰지 않는다. 없는 일정을 지어내면 근거가 흐려지고, 순연 경기는
  어차피 편성일이 공지되면 다음 갱신 때 그대로 들어오기 때문이다. 진행 중인 시즌은
  15분마다 다시 읽으므로 경기가 끝나는 대로 승패와 잔여 경기가 함께 갱신된다
