# 구단 엠블럼

`TeamBadge` 가 여기 있는 파일을 읽는다. 구단 ↔ 파일 연결은
`src/lib/team-assets.ts` 의 `logo` 필드 한 줄이다.

```ts
LG: {
  ...
  logo: 'lg.png',   // -> public/teams/lg.png
},
```

`logo: null` 이면 이미지 없이 구단 상징색 배지로 표시된다. 파일 이름을 적었는데
파일이 없으면 자동으로 배지로 되돌아간다(`TeamBadge` 의 onError). 파일 하나만
바꿔도 경기 카드·순위표·선수 랭킹·선수 검색·경기 상세·AI 모달까지 같이 바뀐다.

## 지금 들어 있는 파일

각 구단이 **현재 사용하는 공식 엠블럼**, 200×200 PNG. 출처와 채택 연도는
`CREDITS.json` 에 구단별로 적어뒀다.

도안은 KBO 공식 사이트(koreabaseball.com)가 서빙하는
`emblem/regular/<채택연도>/<구단코드>.png` 와 대조해 동일함을 확인했다.
KBO 쪽 파일은 81×59 라 배지에 쓰기엔 너무 작아서, 같은 도안을 200×200 으로
제공하는 네이버 스포츠 CDN 파일을 받았다. 이 앱이 이미 경기 데이터를 네이버
스포츠 API 에서 가져오고 있어 출처도 일치한다.

엠블럼 채택 연도는 구단마다 다르다. 두산·한화는 2025년, SSG 는 2024년,
나머지는 2022년 도안이다. 구단이 엠블럼을 바꾸면 KBO 사이트의 연도 폴더가
바뀌므로 거기서 확인하면 된다.

### 배경을 깔지 않는 이유

구단 공식 엠블럼은 자기 색과 형태를 다 갖고 있어서 라이트·다크 배경 모두에서
그대로 읽힌다. 그래서 `TeamBadge` 는 로고를 쓸 때 배경 칩을 깔지 않는다.
(모자에 붙는 흰색 실루엣 엠블럼을 쓸 때는 어두운 칩이 필요했지만, 그건 지금
쓰는 도안이 아니다.)

엠블럼에 구단명 텍스트가 들어 있어서 아주 작게 쓰면 읽히지 않는다.
표 안에서도 24~26px 아래로는 내리지 않는 것이 좋다.

## 라이선스 — 퍼블릭 도메인이 아니다

이 파일들은 **각 구단이 보유한 등록상표**이고 저작물이다. 경기 정보를
보여주면서 구단을 지칭하는 비상업적 용도를 전제로 넣었다.

광고·결제 등 수익이 붙는 서비스로 운영할 계획이라면 KBO 및 각 구단의 정식
라이선스 절차를 밟아야 한다. 그게 부담스러우면
`src/lib/team-assets.ts` 의 `logo` 를 전부 `null` 로 되돌리면 되고, 그러면
구단 상징색 배지로 표시된다 — 화면 구조는 그대로다.

## 파일을 교체할 때는 버전을 올린다

파일 이름을 그대로 두고 내용만 바꾸면 브라우저가 예전 이미지를 캐시에서 그대로
내준다. 실제로 커먼즈 엠블럼에서 구단 공식 엠블럼으로 갈아끼울 때, 확장자가
`.svg → .png` 로 바뀐 7개 구단만 갱신되고 이름이 같았던 `ssg.png`,
`hanwha.png`, `kiwoom.png` 세 개가 옛 이미지로 남아 있었다.

그래서 `src/lib/team-assets.ts` 의 `TEAM_LOGO_VERSION` 을 올리면 URL 에
`?v=N` 이 붙어 캐시가 무효화된다. **엠블럼 파일을 바꿀 때마다 이 숫자를
같이 올린다.**
